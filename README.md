# CellStim
CellStim — Electrical Cell Stimulation & Signal Acquisition; 
Desktop software for electrode-based cell stimulation and experimental signal recording using the L-Card E20-10 ADC/DAC module.

📖 Аннотация проекта
---
Репозиторий содержит исходный код программного комплекса для электрической стимуляции клеток через электроды и одновременной регистрации их отклика. Аппаратной основой служит USB-модуль АЦП/ЦАП L-Card E20-10, управление которым выполняется через библиотеку Lusbapi.

Программа формирует на выходе ЦАП последовательность прямоугольных импульсов с заданными амплитудой, длительностью, числом и интервалом, а АЦП в это время непрерывно записывает сигнал с измерительных каналов. Результаты сохраняются в файлы данных с метаданными (параметры стимуляции и регистрации, время эксперимента, комментарий оператора) и могут быть позже открыты для просмотра и анализа.

Главная научная и практическая задача комплекса: воспроизводимая стимуляция препарата с точно заданными параметрами и запись данных без потерь, чтобы результаты разных экспериментов можно было сопоставлять.

✨ Функциональные возможности
---
* **Стимуляция:** генерация серии прямоугольных импульсов на ЦАП (амплитуда, длительность, количество, интервал между импульсами) с задержкой запуска относительно начала записи АЦП.
* **Непрерывная регистрация:** потоковый сбор данных с 4 каналов АЦП модуля E20-10 с двойной буферизацией и записью на диск в реальном времени; выбор диапазона входного напряжения (3000 / 1000 / 300 мВ).
* **Отображение в реальном времени:** график сигнала выбранного канала во время записи, масштабирование колёсиком и выделением области.
* **Автоматизация записи:** имя файла формируется из произвольного имени и номера эксперимента с автоматическим инкрементом, поле для комментария оператора, фоновая конвертация сырых данных в файлы по каналам с метаданными.
* **Просмотр файлов:** загрузка сохранённых записей, график с зумом и курсором, сводка параметров и статистика сигнала (минимум, максимум, среднее, размах, RMS).
* **В разработке (по ТЗ):** режим «бесконечной» записи, усреднение серий с чтением и записью усреднённых массивов, диаграммы стимуляции из текстовых файлов (время, напряжение, признак записи), проверка параметров на допустимые пределы с предупреждениями, длительные эксперименты с серией до 1000 импульсов.

🛠️ Программный и аппаратный стек
---
* **Язык и платформа:** `C++/CLI`, `.NET Framework 4.7.2+`, `Windows Forms`
* **Среда сборки:** `Visual Studio 2019/2022`, платформа `x64`
* **Графики:** `System.Windows.Forms.DataVisualization.Charting`
* **Работа с модулем:** `L-Card Lusbapi` (`Lusbapi.dll`, `Lusbapi.lib`)
* **Оборудование:** модуль `L-Card E20-10` (4 канала АЦП, 2 канала ЦАП 12 бит, выход ±5 В), подключение по USB

📂 Архитектура репозитория
---
* `/CLRprj/CLRprj` - исходный код приложения:
  * `MyForm.cpp/h` - графический интерфейс и обработчики событий;
  * `E2010Controller.cpp/h` - работа с модулем: ЦАП, АЦП, потоки чтения и эксперимента;
  * `ADCFile.cpp/h`, `ExperimentData.h` - формат файлов данных и метаданные;
  * `GraphBufferNative.h` - буфер данных для отображения в реальном времени.
* `/Examples` - примеры L-Card по работе с модулем (Borland C++, Delphi, Visual C++).
* `/*.pdf` - техническая документация модуля E20-10 и библиотеки Lusbapi.

🚀 Быстрый старт
---
1. Откройте `CLRprj.sln` в Visual Studio, выберите платформу **x64** и соберите решение.
2. Подключите модуль E20-10 по USB и установите драйвер L-Card.
3. На вкладке **Storage** выберите папку для данных.
4. На вкладке **DAC** задайте параметры импульсов, на вкладке **ADC** - параметры записи и запустите регистрацию или эксперимент.
